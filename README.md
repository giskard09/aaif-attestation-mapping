# aaif-attestation-mapping

Our own mapping of existing specs (`action_ref`, `execution-join-ref-v1`,
`idempotency-ref`, `revocation-ref`, all in
[giskard09/argentum-core](https://github.com/giskard09/argentum-core))
against empirical gaps named in the AAIF Observability & Traceability
Working Group's own survey (27 coding agents, 34 SDKs).

See [`MAPPING.md`](MAPPING.md) for the gap-by-gap mapping, and
[`PROVENANCE.md`](PROVENANCE.md) for exact source pins.

**Not posted anywhere.** This is a private-review artifact — it has not
been shared with, reviewed by, or endorsed by anyone in the AAIF WG, and
nothing here comments on or references any specific person in the group.

## Why this exists as its own repo

Same pattern as
[`execution-join-ref-remora-bridge`](https://github.com/giskard09/execution-join-ref-remora-bridge):
a self-contained artifact that can be read, linked, or handed over on its
own terms, separate from any GitHub thread.
